# Data Dictionary

| Variable Name | File | Type | Units | Range | Description |
|---|---|---|---|---|---|
| `timestamp` | All CSVs | ISO-8601 Datetime | UTC | 2023-01-01 00:00 to 2023-12-31 23:00 | Hourly index |
| `pv_generation_kw` | `pv.csv` | Float | kW | [0.000, 5.000] | Measured behind-the-meter rooftop solar generation |
| `load_kw` | `load.csv` | Float | kW | [0.056, 3.331] | Inflexible domestic household consumption |
| `price_per_kwh` | `tariff.csv` | Float | USD / kWh | [0.080, 0.250] | Electricity import tariff from the main distribution grid |
| `pv_forecast` | Internal / Results | Float | kW | [0.000, 5.000] | Point forecast generated by HistGradientBoosting model |
| `pv_forecast_low` | Internal / Results | Float | kW | [0.000, 5.000] | Lower 90% conformal prediction bound ($\max(0, \hat{G}_t - q_\alpha)$) |
| `pv_forecast_high` | Internal / Results | Float | kW | [0.000, 5.000] | Upper 90% conformal prediction bound ($\min(P_{\text{cap}}, \hat{G}_t + q_\alpha)$) |
| `reliability_score` | Results | Float | Dimensionless | [0.000, 1.000] | Horizon-average prediction reliability metric |
| `charging_power` | Results | Float | kW | [0.000, 7.000] | Commanded EV charging power rate |
| `grid_import` | Results | Float | kW | [0.000, 10.000+] | Realized power drawn from the distribution grid |
| `export` | Results | Float | kW | [0.000, 5.000] | Realized surplus solar power injected into the grid |
| `total_cost` | Results | Float | USD | $\ge 0.000$ | Realized daily electricity bill for the residence |
| `deadline_met` | Results | Boolean | True / False | {0, 1} | Indicator of whether $E_{\text{departure}} \ge E_{\text{target}}$ |
| `unmet_energy_kwh` | Results | Float | kWh | $\ge 0.000$ | Energy deficit below target at session departure |
